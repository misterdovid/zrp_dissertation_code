The folder contains code which was used to create some of the visual aspects of my project. 
All code was produced using generative AI, including Claude and ChatGPT.
I am, however, responsible for the design and accuracy of these programs,
through extensive iteration and testing.

zrp_grapher: these MATLAB files were used to create the plots in my dissertation
zrp_simulator: this HTML file simulates a ZRP for any underlying graph, density and rate u(n)
strang-tree tool: this allowed me to encode tree graphs as graph6 strings which could then be fed into the zrp_simulator
